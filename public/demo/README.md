# Cueflow demo audio sources

The packaged demo audio is derived from public-domain recordings hosted by Wikimedia Commons.

| Cue file | Source | Licence |
| --- | --- | --- |
| `door-bell.mp3` | [Sound Effect - Door Bell.ogg](https://commons.wikimedia.org/wiki/File:Sound_Effect_-_Door_Bell.ogg) by Amada44 | CC0, public domain |
| `thunder-roll.mp3` | [Storm thunderbolts.ogg](https://commons.wikimedia.org/wiki/File:Storm_thunderbolts.ogg), transferred by Fæ from a PDSounds public-domain recording | Public domain |
| `applause.mp3` | [Applause ii.ogg](https://commons.wikimedia.org/wiki/File:Applause_ii.ogg), transferred by Fæ from a PDSounds public-domain recording | Public domain |

Cueflow trims the long thunder recording to eight seconds and converts the three OGG sources to compact MP3 files for broad browser playback. The files are demo assets only and do not enter a user account or cloud project.
