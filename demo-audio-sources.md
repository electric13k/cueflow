# Cueflow demo audio provenance

The replacement demo recordings were sourced from Wikimedia Commons file pages inspected during this task.

| Local file | Source URL | Licence and relevant details |
| --- | --- | --- |
| `public/demo/door-bell.mp3` | https://commons.wikimedia.org/wiki/File:Sound_Effect_-_Door_Bell.ogg | CC0, public domain. Original OGG is 3.7 seconds. Author listed as Amada44. |
| `public/demo/thunder-roll.mp3` | https://commons.wikimedia.org/wiki/File:Storm_thunderbolts.ogg | Public domain. Original recording is a 5 minute 3 second thunder recording transferred from PDSounds. Cueflow trims it to 8 seconds for the demo. |
| `public/demo/applause.mp3` | https://commons.wikimedia.org/wiki/File:Applause_ii.ogg | Public domain. Original recording is approximately 11 seconds of auditorium applause, transferred from PDSounds. |

The source pages expose the original file URLs on upload.wikimedia.org. Cueflow converts the OGG recordings to compact MP3 files for broad browser playback. The files are local demo assets and are not uploaded to user accounts or cloud projects.
